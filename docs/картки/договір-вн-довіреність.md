# Договір, ВН, довіреність, «до сплати», оплата

## Коли

Закупівельники уклали договір; постачальник надіслав ВН чи рахунок; ФЕС видала довіреність; командир
наклав резолюцію «до сплати»; ФЕС провела оплату.

## Що потрібно

Договір (№, дата, сума з ПДВ, строк поставки, № процедури UA-…), ВН чи рахунок, довіреність М-2
(кому, дійсна до), дата резолюції «до сплати», дата й сума оплати з виписки.

## У програмі

Картка закупівлі → «Договори» → «+ Договір»; у рядку договору «+ ВН» (сума, «до сплати», статус
ФЕС), «+ Довіреність» (кому, дійсна до, використана, повернута); у рядку ВН «+ Оплата». Документ, що
бере з кількох рядків коштів, — частками, які дають його суму до копійки. «Підшити скан» — у рядку
документа.

## Без програми

Книга «Закупівлі», аркуш «Документи»: вид, номер, дата, закупівля, контрагент, сума, ПДВ, «до
документа» (ВН → договір, оплата → ВН), «до сплати», строк поставки, дійсна до; «Частки» — коли
рядків коштів кілька; «Рядки документів» — позиції ВН. Довіреність, що стоїть під договором,
зараховується всім ВН договору; ВН без договору — лише довіреність, що стоїть під нею самою.

## Куди покласти

Договір — у теку закупівлі: «Договір №… від … (постачальник)». ВН, рахунки, довіреності, оплати — у
«Прибутково-видаткові документи/<рік>/Отримання/», де <рік> — рік дати самого документа, під назвами
«ВН №… від … (постачальник)», «Рахунок №… від … (контрагент)», «Довіреність №… від … (контрагент)»,
«Оплата №… від … (контрагент)»; скан — поруч під тією самою назвою.
