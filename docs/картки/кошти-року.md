# Кошти року: рядки коштів, рух і залишки за формулами штабу

## Коли

Штаб чи громада виділили кошти або змінили суму; надійшло фінансування; ФЕС провела оплату;
щомісяця перед звітом «Використання коштів».

## Що потрібно

Лист чи таблиця штабу із сумою на рік, виписка або повідомлення ФЕС про фінансування й оплати; для
субвенції — рішення й угода громади.

## У програмі

«Закупівлі» → «Кошти» → «+ Рядок коштів»: назва (унікальна в році, наприклад «ПДФО 3110/040»), фонд,
КПКВ, КЕКВ, код видатків; для субвенції — ще громада, угода, рішення, строки. У картці рядка
«+ Запис руху»: затверджено, зміна (сума зі знаком), профінансовано, повернуто. Оплату вносять у
закупівлі: «+ Оплата» під ВН чи рахунком. Показники рахує програма: на екрані «Кошти» — затверджено,
профінансовано, зобов'язання, поставлено, використано, залишок коштів, без договору, не
розплановано; залишок бюджетних зобов'язань і відсотки — у звіті «Звіти…» → «Використання коштів».

## Без програми

Книга «Закупівлі»: аркуш «Кошти» — рядок на рядок коштів, «Рух коштів» — рядок на запис: рядок
коштів, дата, вид, сума, підстава. Формули штабу: затверджено = записи «затверджено» + «зміна»;
профінансовано = «профінансовано» − «повернуто»; зобов'язання — сума договорів; використано — сума
оплат; залишок бюджетних зобов'язань = затверджено − зобов'язання; без договору = профінансовано −
зобов'язання; залишок коштів = профінансовано − використано; % взяття = зобов'язання / затверджено;
% від фінансування = зобов'язання / профінансовано; % використання = використано / профінансовано.
На аркуші «Кошти» Excel рахує шість граф (затверджено, профінансовано, зобов'язання, використано,
залишок коштів, без договору) — їх не правлять; решту рахують за формулами вище. Документ без
частки йде цілим до рядка коштів у колонці «рядок коштів» аркуша «Документи»; коли рядків кілька —
аркуш «Частки».

## Куди покласти

Лист, угоду, рішення — у «Закупівлі/<рік>/Кошти/<назва рядка>/» (знаки, яких не терпить ім'я теки, у
назві рядка там стають «-», зокрема «/»);
книга «Закупівлі.xlsx» — у корені теки «Закупівлі».
